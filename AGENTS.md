# Yemen Opportunities Portal - Project Rules

- Arabic is the primary interface language, with full English support.
- Arabic UI must use correct RTL direction; English content must use correct LTR direction where needed.
- The interface must work correctly at 360px width without horizontal scrolling.
- Do not load libraries, fonts, icons, scripts, or styles from CDNs.
- Do not install any new package without asking first.
- Never delete files. If removal is necessary, move the file to _trash instead.
- Never read, expose, or modify .env files, credentials, passwords, API keys, or secrets.
- Never access files outside this project.
- Opportunity data must never be invented, guessed, or generated.
- Opportunity data must be manually verified by the project owner from official sources.
- Every opportunity must include an official HTTPS source URL and a verification date.
- Do not automatically scrape or modify opportunity data.
- Code comments should be written in English.
- Test every completed feature against its stated success criteria.
- After each completed feature, suggest a clear Git commit message.
- Report failures honestly; never create fake test or user-testing evidence.
