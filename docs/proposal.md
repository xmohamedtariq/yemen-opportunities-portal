# Opportunities Portal

## 1. Problem Statement

Many Yemeni students and young people struggle to find scholarships, free courses, internships, and professional development opportunities at the right time.

Information is often scattered across many different websites, and students may only hear about an opportunity shortly before the deadline or after applications have already closed.

The purpose of the Opportunities Portal is to collect a limited number of manually verified opportunities from official sources and present them in a simple web application that helps users search, filter, save, and track important deadlines.

## 2. Target Users

The primary users are Yemeni students and young people looking for:

- Scholarships
- Free educational courses
- Internships
- Academic and professional development programs

The application should be easy to use on mobile devices and suitable for users with slow or unstable internet connections.

## 3. User Stories

### US-01 - Search
As a Yemeni student, I want to search opportunities using keywords so that I can quickly find opportunities related to my interests.

### US-02 - Filtering
As a Yemeni student, I want to filter opportunities by country, field of study, and education level so that I do not have to review irrelevant opportunities.

### US-03 - Deadline Tracking
As a student in Yemen, I want to see opportunities that are closing soon so that I do not miss application deadlines.

### US-04 - Opportunity Details
As a student, I want to open an opportunity details page and see the provider, deadline, official source link, and verification date so that I can verify the information myself.

### US-05 - Favorites
As a student, I want to save interesting opportunities to a favorites list so that I can easily return to them later.

### US-06 - Mobile Access
As a mobile user, I want the application to work clearly on a 360px-wide screen so that I can comfortably use it on my phone.

### US-07 - Offline Access
As a user with unstable internet access, I want to use the main application features after previously loading the website so that I can still access useful information when my connection is unavailable.

## 4. Scope of the First Version

The first version will include:

- At least 20 real opportunities
- Keyword search
- Opportunity filtering
- Deadline tracking
- Opportunity details
- Official source links
- Verification date for every opportunity
- Favorites
- Arabic user interface
- English language support
- Mobile-responsive design
- Basic offline functionality using a Service Worker

## 5. Out of Scope

The first version will not include:

- User accounts
- Applying for opportunities on behalf of users
- Storage of sensitive personal information
- AI-generated opportunities
- Automatic web scraping
- Automatic modification of opportunity data
- Automatic application submission
- Guaranteed eligibility or acceptance decisions
- A cloud database or backend unless later proven necessary

## 6. Data Source Policy

Opportunity data will not be generated by an AI model.

Each opportunity will be collected manually from its official source.

For every opportunity, the application will store:

- The official source URL
- The date on which the information was manually verified

Users will always be able to check the original official source before making an application decision.

## 7. Success Criteria

The first version will be considered successful when a user can:

1. Open the application on a mobile device.
2. Search for an opportunity.
3. Filter the available opportunities.
4. Open the details of an opportunity.
5. View its deadline and official source.
6. Save an opportunity to favorites.
7. Identify opportunities with approaching deadlines.
8. Use the main application features offline after previously loading the application.
